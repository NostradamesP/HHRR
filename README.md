# Kanban IT Departament

Kanban operativo para planificar y gestionar tareas del departamento de IT.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Probar build

```bash
npm run build
npm run preview
```

## Deploy en GitHub Pages

Este proyecto incluye `.github/workflows/deploy.yml`.

En GitHub ve a:

```txt
Settings → Pages → Source → GitHub Actions
```

Luego haz push a `main`.

## Commit recomendado

```bash
git add .
git commit -m "Fix NoraHR roadmap GitHub Pages deployment"
```
